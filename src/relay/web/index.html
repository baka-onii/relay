Agent settings

Two models. One thoughtfully controlled loop.

OpenAI-style: llama.cpp, Ollama, OpenAI, OpenRouter, Together, Groq, Google AI Studio. Anthropic-style: Anthropic or an Anthropic-compatible proxy.

Custom APIs welcome: point the URL at any OpenAI- or Anthropic-styled endpoint and pick its style above. This URL must be reachable from the Python server, not just your browser. The key is never saved, exported, or shown again.

No key needed for local servers. For a hosted provider, paste your key above (session-only, never saved) or set RELAY_LLM_API_KEY in the server’s environment.

Runtime & permissions

Severe actions (delete, code execution, text edits, commits) need your approval in this console. Confidence alone is never permission.

Model output & timing

Long file payloads need room in both models. These limits affect live inference, not demo planning.

Workspace context & tool limits

Paths are always relative to . Change the server workspace with --workspace or your config file.

Appearance

Stored in this browser only. The base color tints the workspace background, sidebar, top bar, cards, inputs, and dialogs; the accent color highlights actions and selections. Small status tints keep their designed colors.

Streaming & model conversation

A short buffer smooths uneven token delivery. Text follows measured output speed and catches up at the end. Set the buffer to 0 for immediate updates. Reduced-motion preferences skip the typing animation. Tool execution and approval prompts are never delayed by display pacing.

Reasoning, translation & confirmation prompts

Applied to the next run. Actual tools and workspace metadata are attached automatically. Custom text cannot disable validation, confidence gates, or permissions.

Settings are session-local. Export a portable TOML file to keep them, then use relay serve --config relay.toml. Imports apply immediately and must embed prompt text; server paths and weights are not changed. Keys are never exported.

Delete conversation?

This removes the conversation and its run history from this browser session. Workspace files are not deleted. This cannot be undone.
